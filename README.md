# Tech Pulse — Editorial Blog Template

A clean, minimalist, high-end editorial blog built with React, Vite, Tailwind CSS, React Router, and Lucide icons.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Pages
- `/` — Home (featured post + latest stories + sidebar)
- `/about` — Editorial Mission
- `/newest` — Newest Blogs grid

## Design notes
- Pure white background, sharp black typography
- Playfair Display (serif) for headings, Inter (sans) for body
- Orange-600 (#EA580C) used as the only accent
- Fully responsive: 12-column grid collapses on mobile
